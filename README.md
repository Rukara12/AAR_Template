# 리뷰 템플릿

디시인사이드에 **게임 리뷰**를 올릴 때 쓰는 이미지 생성기입니다.
카드를 끌어다 쌓아 한 편을 만들고, 그대로 이미지로 뽑아 갤러리에 올립니다.

브라우저에서만 돌아갑니다. 넣은 이미지는 어디에도 올라가지 않고 내 컴퓨터 안에서만 처리됩니다.

---

## 쓰는 법

1. 시작 화면에서 **리뷰 카드**를 고릅니다. 표지 · 게임 정보 · 평점 · 장단점 · 총평이 깔립니다.
2. 표지 카드에 **스팀 상점 주소**를 넣고 **가져오기**. 헤더 이미지와 게임 정보가 한꺼번에 채워집니다.
3. **가운데 미리보기에서 바로 고칩니다.** 글은 눌러서, 이미지는 끌어서.
4. **내보내기**로 저장해 갤러리에 올립니다.

카드를 더 넣으려면 왼쪽 **카드 팔레트**에서 아래 **문서 구성**으로 끌어다 놓으세요.
(클릭하면 맨 아래 추가) 타일에 커서를 올리면 그 카드 견본이 크게 뜹니다.

## 미리보기에서 바로 고치기

가운데 미리보기가 곧 편집기입니다. 커서를 올리면 고칠 수 있는 자리에 테두리가 뜹니다.

| 대상 | 동작 |
| --- | --- |
| 글 | **누르면** 그 자리에 입력칸이 열립니다. `Esc` 취소, `Ctrl+Enter` 확정 |
| 이미지 | **끌어서** 위치 옮기기 |
| 이미지 | **`Alt`+휠** 로 확대·축소 (그냥 휠은 화면 넘기기) |
| 이미지 | **더블클릭**으로 확대·위치 되돌리기 |
| 이미지 | 오른쪽 위 **✕** 로 그 사진만 지우기 (빈 자리를 누르면 다시 고릅니다) |
| 평점 막대 | **좌우로 끌어서** 점수 조절 |
| 카드 | 오른쪽 위 **✕** 로 카드째 지우기 |

항목 추가, 정렬·비율 같은 세부 설정은 오른쪽 **카드 속성**에서 합니다.
안 쓸 때는 상단바의 **속성** 버튼으로 접어 둘 수 있습니다.

**문서 구성** 목록에는 카드 종류만 적힙니다. 무엇이 어떤 차례로 있는지 보는 곳입니다.
그 카드에 뭘 적었는지는 커서를 올리면 보입니다.

## 스팀에서 가져오기

**표지 카드**와 **게임 정보 카드**가 같은 주소 칸을 씁니다.
어느 쪽에서 **가져오기**를 눌러도 둘 다 채워집니다.

| 카드 | 채우는 것 |
| --- | --- |
| 표지 | 헤더 이미지, 제목이 비어 있으면 게임 이름 |
| 게임 정보 | 개발자 · 출시일 · 장르 · 가격 · 최근 평가 · 한국어 평가 |

- 이미 적어 둔 **글자 값은 덮어씁니다.**
- **직접 올린 표지 사진은 덮지 않습니다.** (그 표지 카드에서 직접 누르면 새로 받습니다)
- **가격·한국어 평가까지** 체크를 끄면 빨라지지만 그 두 가지는 안 옵니다
- 나이 확인이 걸린 게임은 **최근 평가**만 못 받고 전체 평가로 대신합니다
- 플레이 시간처럼 스팀에 없는 값은 **항목 추가**로 직접 적으세요

표지 사진 규격은 **자세한 설정 → 스팀 규격**에서 고릅니다.
2배·3배로 크게 뽑을 거면 **와이드 히어로(3840×1240)** 가 가장 또렷합니다.

## 이미지 여러 장 한꺼번에

창에 이미지 파일 여러 개를 떨어뜨리면 **그 수만큼 자막 스샷 카드가 생깁니다.**
스샷 20장짜리 리뷰도 한 번에 깔아 놓고 자막만 채우면 됩니다.
(**문서 ▾ → 스샷 여러 장 넣기** 로도 같은 일을 합니다)

## 저장하기

**내보내기**를 누르면 그때 형식·화질을 고릅니다. 평소에는 기본값 그대로 두면 됩니다.

| 항목 | 기본값 | 왜 |
| --- | --- | --- |
| 저장 방식 | 세로 합본 한 장 | 순서가 꼬이지 않고 첨부 개수도 아낍니다 |
| 형식 | WebP | 디시의 강제 축소를 통과합니다 |
| 화질 | 2배 (1700px) | 20MB 한도에 여유가 크므로 3배도 됩니다 |

디시 PC 웹·공식 앱은 올린 이미지를 **850×478 로 강제 축소**하는데, **WebP 는 그 처리를 통과**합니다.
그래서 WebP 2배가 기본입니다. 파일 이름은 날짜로 붙습니다 (`리뷰_260920.webp`).

작업 내용은 브라우저에 자동 저장됩니다. 여러 편을 쓴다면 **문서 ▾ → 보관함** 에 담아 두세요.
다만 브라우저 안에만 있으므로, 오래 남길 것은 **프로젝트 저장**으로 `.json` 파일에 따로 보관하세요.

## 화면이 작게 보일 때

상단바의 **− 100% +** 로 편집기를 최대 200% 까지 키울 수 있습니다.
숫자를 누르면 화면 크기에 맞는 기본값으로 돌아갑니다. 출력 이미지에는 영향이 없습니다.

## 단축키

| 키 | 동작 |
| --- | --- |
| `Ctrl+Z` / `Ctrl+Shift+Z` | 되돌리기 / 다시하기 |
| `Ctrl+클릭` | 카드 여러 장 골라 잡기 |
| `Shift+클릭` | 여기까지 한 번에 고르기 |
| `Alt+↑` `Alt+↓` | 고른 카드를 한 칸 위·아래로 |
| `Delete` | 고른 카드 지우기 |
| `Ctrl+V` | 고른 카드에 이미지 붙여넣기 |
| `Ctrl+S` | 프로젝트 파일로 저장 |
| `?` | 조작법 보기 |

## 카드 종류

> **카드 팔레트와 «빈 카드» 로 시작하기는 아직 실험적입니다.**
> 손이 많이 간 쪽은 **리뷰 카드** 기본 구성입니다.

| 묶음 | 카드 | 쓰임 |
| --- | --- | --- |
| **시작** | 표지 | 스팀 헤더 이미지 |
| | 게임 정보 | 개발자 · 장르 · 출시일 · 가격 · 평가 |
| **본문** | 자막 스샷 | 스크린샷 + 자막. 가장 많이 쓰는 형태 |
| | 나레이션 | 본문 글 |
| | 섹션 제목 | `2. 전투` 같은 큰 구분 |
| | 스샷 묶음 | 여러 장을 2~3열 격자로 (최대 6장) |
| | 좌우 비교 | 전 / 후 두 장 |
| **평가** | 평점 | 항목별 막대 + 총점 (비우면 평균 자동) |
| | 장단점 | 좋은 점 / 아쉬운 점 두 열 |
| | 총평 | 한 줄 평 + 본문. 마무리 |
| **곁들이기** | 인용 강조 | 큰 한 줄 |
| | 장면 전환 | — 10시간 뒤 — |
| **캐릭터** | 캐릭터 대사 | 이미지 + 대사 |
| | 캐릭터 소개 | 등장인물 한 장 |

묶음 제목을 누르면 접힙니다. **캐릭터** 는 처음부터 접혀 있습니다.

## 톤

상단바 **문서 ▾ → 톤** 에서 고릅니다.
기본은 **기본 (검정)** — 무채색이라 어떤 게임 스크린샷 옆에 놓아도 튀지 않습니다.
그 외에 **따뜻한**, **중세·양피지** 가 있습니다.

# 웹에 올리기 (GitHub Pages)

빌드가 필요 없는 정적 사이트라 저장소를 그대로 올리면 됩니다.

### 1. 저장소에 올리기

```bash
git add -A
git commit -m "업데이트"
git push
```

### 2. Pages 켜기 (처음 한 번만)

1. GitHub 저장소 → 위쪽 **Settings**
2. 왼쪽 메뉴 **Pages**
3. **Build and deployment** 의 Source 를 **Deploy from a branch**
4. Branch 를 **main** / **/ (root)** 로 두고 **Save**

1~2분 뒤 같은 화면 위에 주소가 뜹니다.

```
https://rukara12.github.io/AAR_Template/
```

### 3. 그 다음부터

`git push` 할 때마다 자동으로 다시 올라갑니다. 따로 누를 것이 없습니다.
바로 안 바뀌면 브라우저 캐시이니 `Ctrl+Shift+R` 로 새로 고치세요.

> 저장소가 **Private** 이면 Pages 가 안 켜집니다. (무료 계정 기준)
> Settings 맨 아래 **Change repository visibility** 에서 Public 으로 바꾸세요.

`.nojekyll` 파일이 저장소에 있어야 `_` 로 시작하는 파일이 안 잘립니다. 이미 들어 있습니다.

# 내 컴퓨터에서 열 때

`index.html` 을 더블클릭하면 브라우저가 막습니다. 간단한 서버를 띄워 주세요.

```bash
python -m http.server 8080
# http://localhost:8080
```

고쳐도 화면이 그대로면 브라우저 캐시입니다. `Ctrl+Shift+R`.

코드를 고칠 일이 있으면 각 파일 맨 위 주석을 보세요. 무엇을 하는 파일인지 적어 두었습니다.
