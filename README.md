# 리뷰 템플릿

디시인사이드에 올릴 게임 리뷰 이미지를 만듭니다.
브라우저에서만 돌아가며, 넣은 이미지는 밖으로 나가지 않습니다.

## 쓰는 법

1. 시작 화면에서 **리뷰 카드** 선택
2. 표지 카드에 **스팀 상점 주소**를 넣고 **가져오기**
3. 가운데 미리보기에서 바로 수정
4. **내보내기** → 갤러리에 업로드

카드 추가는 왼쪽 **카드 팔레트**에서 **문서 구성**으로 끌어다 놓습니다. 클릭하면 맨 아래 추가.

## 미리보기 조작

| 대상 | 동작 |
| --- | --- |
| 글 | 클릭해서 수정. `Esc` 취소, `Ctrl+Enter` 확정 |
| 이미지 | 드래그로 위치 이동 |
| 이미지 | `Alt`+휠로 확대·축소 |
| 이미지 | 더블클릭으로 되돌리기 |
| 이미지 | 오른쪽 위 **✕** 로 사진만 삭제 |
| 평점 막대 | 좌우 드래그로 점수 조절 |
| 카드 | 오른쪽 위 **✕** 로 카드 삭제 |

항목 추가, 비율·정렬은 오른쪽 **카드 속성**에서.

## 스팀에서 가져오기

표지 카드와 게임 정보 카드가 주소 칸을 공유합니다. 한쪽에서 누르면 둘 다 채워집니다.

| 카드 | 채우는 것 |
| --- | --- |
| 표지 | 헤더 이미지, 게임 제목 |
| 게임 정보 | 개발자 · 출시일 · 장르 · 가격 · 최근 평가 · 한국어 평가 |

- 이미 적은 글자 값은 덮어씁니다
- 직접 올린 표지 사진은 덮지 않습니다
- **가격·한국어 평가까지** 체크를 끄면 빨라지지만 그 둘은 안 옵니다
- 스팀에 없는 값(플레이 시간 등)은 **항목 추가**로 직접 입력

표지 화질은 **자세한 설정 → 스팀 규격**. 2배 이상으로 뽑으면 **와이드 히어로**가 가장 선명합니다.

## 이미지 여러 장

이미지 파일을 창에 떨어뜨리면 그 수만큼 자막 스샷 카드가 생깁니다.
**문서 ▾ → 스샷 여러 장 넣기** 도 동일합니다.

## 내보내기

기본값 그대로 쓰면 됩니다.

| 항목 | 기본값 |
| --- | --- |
| 저장 방식 | 세로 합본 한 장 |
| 형식 | WebP |
| 화질 | 2배 (1700px) |

디시는 PNG·JPG를 850px로 강제 축소하지만 WebP는 통과합니다.

## 저장

브라우저에 자동 저장됩니다.

- **문서 ▾ → 보관함** : 여러 편 보관
- **문서 ▾ → 프로젝트 저장** : `.json` 파일로 내보내기 (브라우저 기록을 지우면 보관함은 사라집니다)

## 단축키

| 키 | 동작 |
| --- | --- |
| `Ctrl+Z` / `Ctrl+Shift+Z` | 되돌리기 / 다시하기 |
| `Ctrl+클릭` | 카드 여러 장 선택 |
| `Shift+클릭` | 범위 선택 |
| `Alt+↑` `Alt+↓` | 선택한 카드 이동 |
| `Delete` | 선택한 카드 삭제 |
| `Ctrl+V` | 선택한 카드에 이미지 붙여넣기 |
| `Ctrl+S` | 프로젝트 저장 |
| `?` | 조작법 |

## 카드 종류

| 묶음 | 카드 | 쓰임 |
| --- | --- | --- |
| **시작** | 표지 | 스팀 헤더 이미지 |
| | 게임 정보 | 개발자 · 장르 · 출시일 · 가격 · 평가 |
| **본문** | 자막 스샷 | 스크린샷 + 자막 |
| | 나레이션 | 본문 글 |
| | 섹션 제목 | 큰 구분 |
| | 스샷 묶음 | 2~3열 격자 (최대 6장) |
| | 좌우 비교 | 전 / 후 두 장 |
| **평가** | 평점 | 항목별 막대 + 총점 |
| | 장단점 | 좋은 점 / 아쉬운 점 |
| | 총평 | 한 줄 평 + 본문 |
| **곁들이기** | 인용 강조 | 큰 한 줄 |
| | 장면 전환 | — 10시간 뒤 — |
| **캐릭터** | 캐릭터 대사 | 이미지 + 대사 |
| | 캐릭터 소개 | 등장인물 한 장 |

> 카드 팔레트와 **빈 카드** 시작은 실험적 기능입니다. **리뷰 카드** 기본 구성을 권장합니다.

## 기타

- **− 100% +** : 편집기 크기 조절 (출력에는 영향 없음)
- **문서 ▾ → 톤** : 기본(검정) · 따뜻한 · 밝은(흰색)
