# 연재 템플릿

디시인사이드에 게임 연재글을 올릴 때 쓰는 **이미지 생성기**입니다.
카드를 끌어다 쌓아 한 회차를 만들고, 그대로 PNG 로 뽑아 갤러리에 올립니다.

브라우저에서만 돌아가고 서버가 없습니다. 이미지는 어디에도 올라가지 않고 내 컴퓨터 안에서만 처리됩니다.

## 왜 이미지로 뽑나

디시 본문은 서식이 거의 남지 않고, 긴 글은 그대로 묻힙니다.
실제로 흥한 연재들(고전게임 갤러리 · 중세게임 갤러리 등)은 대부분 스크린샷에 자막·대사를 얹은 이미지를 순서대로 올리는 방식입니다.

## 디시 업로드 규격

| 항목 | 값 | 이 앱의 대응 |
| --- | --- | --- |
| 가로 폭 | 850px 초과 시 자동 리사이즈 (글씨 뭉개짐) | 출력 폭을 **850px 로 고정** |
| 장당 용량 | 20MB | 넣는 이미지를 850px 로 줄여 보관 |
| 글당 첨부 | 50장 | 낱장이 50장을 넘으면 합본을 쓰세요 |
| 파일명 | 한글·영문·숫자만 안전 | 그 외 문자는 자동으로 `_` 로 바꿈 |

## 쓰는 법

1. 왼쪽 **카드 팔레트**에서 타일을 **회차 구성**으로 끌어다 놓습니다. (클릭하면 맨 아래 추가)
2. 목록에서 카드를 끌어 순서를 바꿉니다.
3. 오른쪽 **카드 속성**에 글을 넣고, 이미지는 끌어놓기 또는 `Ctrl+V` 로 붙여넣습니다.
4. 맨 오른쪽 미리보기가 곧 결과물입니다.
5. **낱장 PNG** 또는 **세로 합본 저장** 으로 내려받아 갤러리에 올립니다.

### 단축키

| 키 | 동작 |
| --- | --- |
| `Ctrl+V` | 고른 카드에 이미지 붙여넣기 |
| `Delete` | 고른 카드 삭제 |
| `Ctrl+Z` | 방금 지운 카드 되살리기 |
| `Ctrl+S` | 프로젝트 파일로 저장 |

작업 내용은 브라우저에 자동 저장됩니다. 다만 이미지가 많으면 용량 한계로 글만 남으므로,
회차를 마쳤으면 **프로젝트 저장**으로 `.json` 파일을 따로 보관하는 편이 안전합니다.

## 카드 종류

| 묶음 | 카드 | 쓰임 |
| --- | --- | --- |
| 뼈대 | 표지 | 회차 시작. 갤러리 썸네일로도 쓰입니다 |
| | 나레이션 | 본문 글 |
| | 다음 화 예고 | 회차 마무리 |
| 이미지 | 자막 스샷 | 스크린샷 + 자막. 가장 많이 쓰는 형태 |
| | 이미지 | 자막 없는 스샷 |
| | 좌우 비교 | 전 / 후 두 장 |
| 인물 | 초상화 대사 | 인물 + 대사. 크킹·패독 연재 형식 |
| | 인물 소개 | 등장인물 카드 |
| 정보 | 상황 요약 | 스탯 + 지난 줄거리. 중간 유입 독자용 |
| 연출 | 인용 강조 | 큰 한 줄 |
| | 장면 전환 | — 3일 후 — |
| 독자 참여 | 선택지 | 번호 선택지 + 투표 안내 |
| | 투표 결과 | 지난 화 개표. 1위 자동 강조 |

## GitHub Pages 배포

저장소 **Settings → Pages → Build and deployment**에서
Source 를 `Deploy from a branch`, Branch 를 `main` / `/ (root)` 로 두면 그대로 올라갑니다.
빌드 과정이 없는 정적 파일이라 별도 워크플로가 필요 없습니다.

## 로컬에서 열 때

ES 모듈을 쓰기 때문에 `index.html` 을 파일로 바로 열면 브라우저가 막습니다.
간단한 서버를 띄워서 열어 주세요.

```bash
python -m http.server 8080
# http://localhost:8080
```

## 카드 새로 만들기

`js/cards/내카드.js` 를 만들고 `registry.js` 에 두 줄만 더하면 끝입니다.
팔레트 · 편집 폼 · 미리보기 · 내보내기는 자동으로 따라옵니다.

```js
import { T } from '../theme.js';
import { W, PAD, CW, text } from '../canvas/layout.js';

export default {
  id: 'mycard',
  name: '내 카드',
  desc: '설명 한 줄',
  group: '연출',
  accent: '#c8973f',

  create: () => ({ body: '' }),

  // 편집 폼은 이 스키마로 자동 생성됩니다.
  // 쓸 수 있는 타입: text textarea number range select toggle image strlist pairs note
  fields: [
    { k: 'body', t: 'textarea', label: '내용', rows: 4 }
  ],

  label: c => c.body || '내 카드',

  // 높이를 먼저 재고, 나중에 그립니다.
  build(c) {
    const body = text(c.body, { size: 20, maxW: CW, lh: 36 });
    const h = 30 + body.h + 30;
    return {
      h,
      paint(ctx) {
        ctx.fillStyle = T.bg;
        ctx.fillRect(0, 0, W, h);
        body.paint(ctx, PAD, 30);
      }
    };
  }
};
```

## 톤 바꾸기

`js/theme.js` 의 색상·폰트 값만 고치면 전체 출력 톤이 한 번에 바뀝니다.
`THEMES` 에 항목을 추가하면 여러 톤을 두고 고를 수도 있습니다.
